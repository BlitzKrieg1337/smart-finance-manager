# Smart Finance Manager

Smart Finance Manager

Description
 - Personal finance manager to track budgets, transactions, goals and investments, with analytics and simple predictions.

Key Features
 - User authentication and session management
 - Transaction, budget, goal, and investment CRUD operations
 - Investment search and live quote lookups (Finnhub + NSE helper)
 - CSV export and import helpers
 - Simple analytics endpoints for dashboards

Tech Stack
 - Backend: Node.js, Express, Mongoose (MongoDB)
 - Frontend: React + Vite
 - Data providers: Finnhub (US stocks & crypto), NSE helper
